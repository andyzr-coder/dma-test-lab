# DMA Lab · 把故障看见

[打开公开学习网站](https://andyzr-coder.github.io/dma-test-lab/)

用中文逐页解释 DMA Lecture 20261110 与 DMA Lecture 20261111 的数字电路测试原理。包含 15 页详细讲解、9 组交互实验、术语表、逐页自测和本地学习进度。

## 学习内容

- 布尔差分、AND / OR / XOR 的变化传播与 Shannon 展开
- 分支、重汇聚、单路径与多路径敏化、故障自掩蔽
- 无扇出树中的链式法则、可观察信号与故障树
- 五值 D 逻辑、前向/后向蕴含、D 算法搜索与回溯
- 全局学习、逆否命题、概率可控性与独立性近似
- 永久故障的时间展开、状态初始化、三拍时序测试序列

内容依据两份课堂笔记独立编写，属于学习辅助解释，并非官方答案。原笔记中的疑似笔误和教学补充例子在对应页面标明。原始 PDF 不随公开网站发布；页面的“对照原笔记”可以在浏览器内打开自己的文件。

## 本地运行

```sh
npm install
npm run dev
```

## 验证与构建

```sh
npm test
npm run build
```

核心测试穷举检查门级差分恒等式、D 逻辑、故障检测条件及不同初始状态下的时序测试。内容校验另检查 15 页覆盖、公式语法与自测选项。

`docs/` 是 GitHub Pages 发布目录。更新网站后，运行 `npm run build`，将 `dist/` 内容同步到 `docs/` 并提交。页面使用相对资源路径和 hash 导航，支持 GitHub Pages 的仓库子路径。

网站不需要登录。学习进度仅使用当前浏览器的 localStorage，本地 PDF 使用临时对象 URL；没有收集学习记录的后端服务。
